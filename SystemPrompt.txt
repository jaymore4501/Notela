💾 STATE & SYNCHRONIZATION ARCHITECTURE
────────────────────────────────────────────────────────────────────────
Notela implements an advanced offline-first state-syncing paradigm:
- Local Storage Cache: Any user activity immediately commits to `localStorage` to ensure instant data availability and zero loading-spinners during editing.
- Sequential Queue Sync Engine: Outgoing API saves are managed sequentially using React references (`syncQueueActiveRef`). This locks parallel server operations, preventing slow network responses from writing out-of-order and corrupting newer local data.
- API Layer: Serializes the user's workspace profile (notes, subjects, tasks, activities, focus stats) into a single document mapped by user email.

🎨 DESIGN SYSTEM & GLASSMORPHISM RULES
────────────────────────────────────────────────────────────────────────
To deliver a jaw-dropping premium look, developers must follow these tokens:
- Backdrop Blurs: Translucent surfaces should utilize `backdrop-blur-md` (12px) to `backdrop-blur-xl` (20px).
- Translucency Opacities: Use white/black alpha values ranging from `0.45` to `0.6` (e.g. `bg-white/50` or `bg-black/40` with borders like `border-white/10`).
- Canvas Colors:
  * Dark Canvas: Deep navy/slate base (`#0f121d` or `#0b0e14`).
  * Light Canvas: Soft off-white light mode base (`#fafafa` or `#f3f4f6`) to prevent screen glare.
- Accent Gradients: Vivid gradients transitioning from deep Indigo (`#6366f1`) to Royal Violet (`#8b5cf6`).
- Interactive Effects:
  * ClickSpark: Emits glowing particle spark grids under the user's pointer on mouse click.
  * ShapeGrid: Smooth canvas grid vector movements behind text grids that adapt dynamically to viewport sizing.
  * BorderGlow: Animated hover borders indicating focus.
  * ShinyText: Reflective light sweep animations across titles.
- Subject Color-Coding:
  * Workspaces: Indigo/Royal Blue tags (`#4F46E5` / `#3B82F6`) on Light Lavender backgrounds.
  * Checklists: Emerald Green (`#10B981` / `#059669`) on Light Mint backgrounds.

🧭 DETAILED FUNCTIONALITIES & CODE RULES
────────────────────────────────────────────────────────────────────────

1. AUTHENTICATION & Protected Routes
   - Custom cookie-based JWT sessions. Cookies are set with secure properties (`HttpOnly`, `SameSite=Lax`, `Secure`).
   - Public landing page (`/`) handles redirection. Authenticated requests automatically route to `/dashboard`.
   - Protect dashboard routes using Next.js routing hooks and React context checks.

2. DASHBOARD HUB
   - Features a dynamic welcome widget displaying the current day and greeting.
   - Show cases the study streak counter, recent note snapshots, incomplete tasks, habit check-ins, and study timer summaries.
   - Provides glassmorphic quick-action cards to immediately add tasks or create documents.

3. CUSTOM RICH-TEXT EDITOR (NOTES SYSTEM)
   - Uses a secure `contentEditable` frame bound to state hooks.
   - Format Painter (Paintbrush): Captures text styles (font family, size, weights, highlights, and colors) from a selection on a clipboard, then applies them to a new selection on `mouseUp` release. Implemented safely by extracting and reinserting Range contents (`extractContents` and `insertNode`) to prevent DOM tree breakage.
   - Line Spacing: Implements an `applyLineHeight` method. Traverses the DOM tree to locate block containers (e.g., `<p>`, `<div>`, list elements, or headings) and updates their `line-height` style directly. Prevents applying spacing styles as inline spans inside inline fragments.
   - Extended Format Tools: Supports bold, italic, underline, alignments, colored text, yellow/cyan/pink highlights, bullet lists, ordered lists, code containers, blockquotes, and tables (adding/removing rows/cols).
   - Dynamic Images: Embeds uploaded images with customizable resizing handles and position alignments.
   - Document Exporting System:
     * PDF: Prints notes natively using a hidden sandbox `iframe` to prevent browser popup block warnings.
     * Word (.docx): Packages document content into well-formed XHTML headers before downloading.
     * High-Definition PNG: Renders the rich-text DOM canvas at **3x scale** onto a high-definition canvas, allowing crisp, ultra-clean picture downloads.
     * JSON Schema: Allows users to backup and import workspace data structures.
   - Autosave: Debounces updates locally prior to queuing synchronization.

4. SUBJECT WORKSPACES
   - Groups notes, due dates, and homework schedules into virtual subject folders.
   - Uses the `@react-bits/Stepper` onboarding flow to guide users through subject configuration.

5. TASK CHECKLISTS
   - Custom tasks with attributes: Due date, Completed status, and Priority levels (Low, Medium, High).
   - Allows users to filter view lists by completion state and search queries.

6. FOCUS TIMER (POMODORO)
   - Study time Tracker. Features adjustable Pomodoro, Short Break, and Long Break configurations.
   - Emits soft, built-in browser audio alerts when intervals conclude.
   - Auto-commits completed focus minutes to the telemetry databases.

7. HABITS & LIFESTYLE (ACTIVITIES)
   - Tracks student habits (such as sleep, fitness, study routines).
   - Interactive checklist grid logging daily metrics and tracking target streaks.

8. PRODUCTIVITY ANALYTICS
   - Displays student activity metrics using Recharts.
   - Includes weekly focus charts, habit consistency bars, and task completion metrics.

9. CLIENT-SIDE GLOBAL SEARCH
   - Searches instantaneously across all note titles, contents, and categorized folders.

🚀 DEPLOYMENT, CASING & CLEANLINESS RULES
────────────────────────────────────────────────────────────────────────
- Casing Verification: Linux hosts (like Render) are strictly case-sensitive. File paths, assets (such as `logo.png` in `public/`), and import declarations must use exact case matching (lowercase file names are preferred).
- Portability & Absolute Paths: Never hardcode absolute paths (`C:/Users/...`). Use relative module mappings (`@/...`) or relative directory symbols (`./`).
- Build Scripts: Verify that the deployment build command chains all package updates securely (e.g., use `npm install && npm run build` on Render environments).
- Secret Safety: Ensure `MONGODB_URI` and `JWT_SECRET` are never exposed in standard files. Place them strictly in local configuration variables or `.env.local` files, with an updated `.env.example` file for new setups.
