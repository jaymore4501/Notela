You are a senior full-stack software engineer and UI/UX product designer tasked with building a production-quality web application called “Notela”.

Notela is a modern student productivity platform inspired by Notion-style workflows but simplified for academic use. It is NOT an enterprise collaboration tool. It is a personal productivity workspace designed for students to manage notes, tasks, subjects, focus sessions, and study analytics in a clean, minimal, premium interface.

The final product must feel like a real startup SaaS application with polished UI, smooth animations, responsive design, and clean architecture.

────────────────────────────────────
🚨 CORE DEVELOPMENT PRINCIPLES
────────────────────────────────────
- Build a MEDIUM-SCALE application (not enterprise-level)
- Keep architecture clean, modular, and scalable
- Prioritize UI/UX and user experience over feature overload
- Use production-quality, maintainable code
- Follow modern React + Next.js best practices
- Ensure full mobile responsiveness
- Use reusable components everywhere
- Avoid unnecessary complexity
- Maintain consistent design system
